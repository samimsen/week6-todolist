# Todo List Uygulaması

Bu proje, basit bir **Yapılacaklar Listesi (Todo List)** uygulamasıdır. Kullanıcılar görev ekleyebilir, görevleri tamamlandı olarak işaretleyebilir ve silebilir. Eklenen görevler **localStorage** üzerinde saklanır, böylece sayfa yenilense bile kaybolmaz.  

Ayrıca, uygulama kullanıcıya **başarı ve hata durumlarını göstermek için toast mesajları** kullanır.

---

## Özellikler

- Görev ekleme
- Görevi tamamlandı olarak işaretleme (toggle)
- Görevi silme
- Ekleme sırasında başarılı veya boş giriş durumunda toast mesajı gösterme
- Görevleri localStorage üzerinde saklama
